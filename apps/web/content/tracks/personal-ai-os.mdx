## Why this track exists

This is the capstone. It takes everything from the other tracks and combines it into one real, running system — a personal AI operating system that researches, builds, publishes, and observes itself.

It is also the track that documents exactly what this site is built on.

## What you will learn

- How to design a full personal AI platform: content, agents, tools, and observability
- How to build a monorepo that scales from a blog to a full AI lab
- How to wire LangGraph agents to MCP tools and a live website
- How to observe everything: token costs, agent runs, errors, latency
- How to publish continuously from an agentic system without losing control

## Who this is for

- Engineers who have completed the Applied AI track and want to build their own platform
- Developers who want to understand how this site was built
- Anyone serious about building in public as a long-term practice

## The system you build

By the end of this track you will have a running personal AI OS: a monorepo with a public website, Python research agents, local MCP servers, and a Langfuse observability dashboard. The same system that powers pranavsrivastava.com.
