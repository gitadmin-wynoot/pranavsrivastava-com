## What you will learn

Computer vision is one of the most mature applied areas of AI. This course covers both classical techniques (which still matter) and deep learning approaches — because understanding why SIFT works makes understanding why CNNs work much clearer.

### Classical computer vision
- Image representation: pixels, channels, colour spaces
- Feature detection: corners, edges, blobs
- SIFT-inspired feature descriptors and matching
- Homography and geometric transformations
- Calibration: checkerboard patterns, camera intrinsics/extrinsics

*These topics are covered from direct project experience including feature point identification and image matching, scene reconstruction using KLT tracking, and camera calibration.*

### Deep learning for vision
- CNNs revisited: why they work for images
- Image classification, localisation, and detection
- Object detection architectures: YOLO, R-CNN family
- Semantic segmentation
- Transfer learning strategies for vision

### Real-time tracking
- Optical flow and the KLT tracker
- Multi-object tracking
- Head pose estimation and facial landmark detection
- Eye gaze detection

*Drawing from OpenFace 2.0 head and eye tracking project work and a research project on student engagement detection using facial expression analysis.*

### Practical applications
- Dataset collection and annotation strategies
- Data augmentation for vision
- Evaluation: mAP, IoU, precision/recall for detection
- Deploying vision models in production

## Course outline

1. Images as data: pixels, colour spaces, representations
2. Classical feature detection: edges, corners, SIFT
3. Feature matching and homography
4. Camera calibration and scene reconstruction
5. CNNs for vision: architecture review
6. Object detection: YOLO and the R-CNN family
7. Tracking: optical flow and KLT
8. Facial analysis: landmarks, pose, gaze
9. Building and deploying a vision system end to end
