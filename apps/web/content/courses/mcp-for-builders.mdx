## What this course covers

MCP (Model Context Protocol) is the standard for connecting AI models to tools and context. This course teaches you to build MCP servers — the things that make those connections work.

By the end, you will have built three real MCP servers and know how to design, secure, and observe them.

## What you will build

- A file access MCP server with read/write controls
- A database query MCP server with parameterized access
- An idea tracker MCP server for personal use

## Course outline

### Lesson 1: MCP concepts
What MCP is, how it works, and why it matters for AI applications.

### Lesson 2: Your first MCP server
Using the Python MCP SDK. Defining tools. Connecting to Claude Code.

### Lesson 3: File access with boundaries
Safe file reading and writing. Whitelisting paths. Logging every access.

### Lesson 4: Database tools
Parameterized queries. Read-only vs read-write tools. Schema-aware tools.

### Lesson 5: Security patterns
Least privilege. Input validation. Never expose shell tools publicly. Transport choices.

### Lesson 6: Observability and debugging
Logging tool calls and results. Connecting to Langfuse. Diagnosing problems.
