## What you will learn

Knowledge graphs make information machine-readable and queryable in a way that flat text cannot. They underpin semantic search, entity resolution, and the grounding layer beneath modern RAG systems.

### Knowledge representation
- Triples: subject, predicate, object — the basic unit
- RDF and the semantic web model
- OWL ontologies: classes, properties, axioms
- Named graphs and provenance
- Knowledge graph vs. property graph (Neo4j vs. RDF stores)

### Querying and reasoning
- SPARQL: the query language for RDF
- Inference and reasoning over ontologies
- RDFS and OWL reasoning rules
- Path queries and graph traversal

### Building knowledge graphs
- Entity extraction from text using NLP
- Relation extraction and co-reference resolution
- Schema design for a domain: entities, relationships, constraints
- Wikidata and DBpedia as public knowledge sources

### Knowledge graphs in modern AI
- Knowledge graph embeddings: TransE, RotatE
- Graph Neural Networks for structured data
- Grounding LLMs with knowledge graphs
- Hybrid RAG: vector similarity + graph traversal

## Course outline

1. The knowledge graph model: triples and RDF
2. Ontologies and OWL
3. SPARQL querying in depth
4. Building KGs from unstructured text
5. Graph databases: RDF stores vs. property graphs
6. Knowledge graph embeddings
7. Graph Neural Networks for relational data
8. Integrating knowledge graphs into AI pipelines
