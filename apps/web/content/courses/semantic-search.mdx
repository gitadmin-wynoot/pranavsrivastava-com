## What you will learn

Semantic search is the retrieval layer that makes AI systems feel like they actually know things. This course builds from how embeddings work to production-grade RAG pipelines.

### How embeddings work
- Dense representations: from word vectors to sentence transformers
- Cosine similarity and inner product — what the numbers mean
- Embedding model families: BGE, E5, OpenAI, Cohere
- Choosing an embedding model for your use case

### Vector databases
- ANN (approximate nearest neighbour) algorithms: HNSW, IVF
- pgvector: vector search inside PostgreSQL
- Dedicated stores: Pinecone, Weaviate, Qdrant
- Indexing strategies, metadata filtering, and namespacing

### Hybrid retrieval
- Why pure dense search fails for exact terms and rare tokens
- BM25 and sparse retrieval
- Reciprocal Rank Fusion (RRF) for combining rankings
- Re-ranking with a cross-encoder

### RAG pipelines
- Chunking strategies: fixed, recursive, semantic, late chunking
- Document ingestion and embedding pipelines
- Query routing and rewriting
- Context window management and citation
- Evaluating RAG: faithfulness, relevance, grounding

### Production concerns
- Embedding drift when models update
- Cost and latency trade-offs
- Caching and tiered retrieval
- Building RAG that agents can use

## Course outline

1. How dense embeddings represent meaning
2. Choosing and comparing embedding models
3. Vector database fundamentals: HNSW and IVF
4. pgvector: vector search in PostgreSQL
5. Dedicated vector stores: Pinecone and Qdrant
6. Hybrid search: dense + sparse + re-ranking
7. Building a RAG pipeline end to end
8. Production RAG: evaluation, caching, and drift
