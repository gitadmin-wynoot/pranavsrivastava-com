## The problem this course solves

Most AI agent tutorials show you how to build an agent. Very few show you how to run one safely and sustainably.

This course covers both. You will build LangGraph agents and instrument them with full observability from the start.

## What you will learn

- How to structure LangGraph workflows for maintainability
- How to add Langfuse tracing to any LangGraph agent
- How to track token usage and cost per task
- How to implement human-in-the-loop approval for consequential actions
- How to handle errors, retries, and budget limits
- How to read your observability data to improve your agents

## Course outline

### Lesson 1: LangGraph fundamentals
State, nodes, edges, and the loop pattern. Why LangGraph instead of simple chains.

### Lesson 2: Building your first observable agent
Adding Langfuse callbacks from the start. Understanding what a trace tells you.

### Lesson 3: Token budgets and cost control
Setting limits. Stopping agents that run away. Alerting on unexpected costs.

### Lesson 4: Tool calls and logging
Logging every tool call with input and output. Finding issues in traces. Safe error recovery.

### Lesson 5: Human-in-the-loop
Pausing workflows for approval. Consequential actions. The approval queue pattern.

### Lesson 6: Error handling and retries
Graceful degradation. Retry with backoff. Distinguishing transient from permanent failures.

### Lesson 7: Reading your data
Using Langfuse dashboards. Identifying expensive tasks. Finding patterns in failures.
