## The mountain is the architecture

Everest turns production engineering into an interactive system map. Requests climb between processing stages, Sherpas coordinate as agents, and radio stations expose tools through MCP. Rotate the terrain, inspect a camp, and watch an architecture decision change latency, quality, cost and reliability.

Follow the guided expedition from model adaptation to evaluation, diagnose a production incident, build your own architecture, or explore the mountain freely. A seeded simulation makes each comparison repeatable, and a written debrief explains the consequences of your decisions.

The MCP inspector uses the official SDK with isolated fixture servers. No account, model API key or external infrastructure is required. This is a software engineering simulation using an expedition metaphor, not mountaineering or safety guidance.
